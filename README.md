# НОЛЬ / nolla

Математична карткова дуель на React, TypeScript і Vite. Проєкт із початкового архіву, підготовлений для Vercel.

## Запуск

Node.js 22.12+ (на Vercel налаштовано 22.x).

```sh
npm ci
npm run dev
```

```sh
npm test           # перевірка ігрових сценаріїв
npm run typecheck  # перевірка TypeScript
npm run build     # перевірка TypeScript + production-збірка у dist/
npm run preview   # перегляд production-збірки локально
```

## Що змінено

- HP може бути від’ємним у межах −999…999. Перехід через нуль не означає поразку: 2 − 3 = −1, гра триває. Лише рівно 0 активує «Обнулення» з ходом для порятунку.
- Додано дві карти «Модуль» |x| у кожну колоду. Вартість — 2 ОО. Працює на числовому HP будь-якого гравця: −7 → 7, 7 → 7, 0 → 0. Не застосовується до рівнянь/графіків і не рятує з нуля.
- «mod 3» залишається окремою картою остачі від ділення; вона дає результат 0, 1 або 2, зокрема для від’ємних чисел.
- Квадратний корінь і факторіал від’ємного HP недоступні. Факторіал дозволений для 0…6.
- Ділення й вибір кореня, як у прототипі, округлюються вниз: −3 ÷ 2 = −2. «Дзеркало» зберігає знак: −21 → −12.
- Від’ємні корені можна зафіксувати як HP; «Скасування» обирає найбільший дійсний корінь, включно з від’ємними.
- Шкала HP має нуль посередині; від’ємні значення показано фіолетовим. Бот оцінює відстань до нуля за модулем.
- Додано головоломки «По той бік нуля» та «Сила модуля», оновлено правила й демонстрацію в меню.

## Заміна змінної та порятунок від ÷0

- **Заміна змінної** `x↦`: 2 ОО, дві карти в колоді. Для свого або чужого рівняння оберіть `x → x ± 1` або `x → x ± 3`. Підстановка змінює весь поліном, зберігає степінь і зміщує корені. Наприклад, `x² − 5x = 0` після `x → x + 1` стає `x² − 3x − 4 = 0`, корені 0 і 5 переходять у −1 та 4. На графіку або числі карта недоступна.
- **Ділення на нуль на числовому HP** тепер спричиняє критичний «Колапс», а не миттєву поразку. Є один власний хід на порятунок; невизначене HP не бере участі у звичайних математичних операціях.
- **Відкат** `↶`: 1 ОО, дві карти в колоді. Лише на себе після ÷0: скасовує колапс і повертає попереднє числове HP, зокрема від’ємне. Порятунок завершує хід. Якщо попереднє HP було 0, воно залишається критичним; Відкат не лікує звичайне Обнулення.
- **Обмін** `⇄` також може врятувати від колапсу: передає невизначений стан супернику та забирає його HP. `0!` та `x⁰` колапс не скасовують.
- Без порятунку — поразка наприкінці власного ходу. У фінальній серії ціль без карток програє за чинним правилом виснаження. На рівнянні ÷0 лишає 1 HP, на графіку — миттєва поразка, як раніше.
- Додано головоломки 09 та 10 для обох механік.

## Vercel

1. Імпортуйте репозиторій `2sparta/nolla` у Vercel.
2. Root Directory — корінь репозиторію.
3. Параметри задані у `vercel.json`: Vite, `npm ci`, `npm run build`, Output Directory `dist`.
4. Натисніть Deploy. Змінні середовища для цієї версії не потрібні.

Додаток працює в браузері з ботом і локальними головоломками. Сервер та онлайн-кімнати поки не реалізовані. Поточний інтерфейс не використовує URL-маршрути, тому SPA rewrite не потрібен.

Офіційна документація: https://vercel.com/docs/frameworks/frontend/vite

## Ідеї наступних оновлень

1. **Зміна знака (−x):** −5 ↔ 5; разом із «Модулем» і додаванням відкриває нові комбінації.
2. **Збереження партії:** продовжити гру після оновлення сторінки; історія матчів і повтор ходів.
3. **Складність бота:** навчальний режим із поясненням та сильніший бот, який прораховує відповідь суперника.
4. **Редактор колоди:** обмеження кількості карт, готові набори «Арифметика», «Алгебра», «Графіки».
5. **Точні дроби:** зберігати 1/2 як дріб без округлення; це окрема зміна правил і математичного рушія.
6. **Онлайн-кімнати за кодом:** гра з другом. Для синхронізації ходів знадобиться окремий backend/realtime-сервіс, сайт можна залишити на Vercel.
